# LitLauncher — туториал

Лаунчер Minecraft: Java Edition с мастером настройки и оптимизированным запуском.

## 1. Получить .exe и установщик Setup

Windows-`.exe` собирается на Windows. Есть два способа, выбери любой.

### Способ A: на своём ПК (build.bat)

1. Поставь **Python 3.8+** с https://www.python.org/downloads/ (отметь **Add python.exe to PATH**).
2. Запусти `build.bat` двойным кликом. Он сам:
   - установит PyInstaller,
   - соберёт `dist\LitLauncher.exe`,
   - установит Inno Setup через winget (если его нет) и соберёт `dist\LitLauncher-Setup.exe`.
3. Готово: в папке `dist` лежат
   - `LitLauncher-Setup.exe` — установщик (ярлык на рабочем столе, удаление через «Программы и компоненты»),
   - `LitLauncher.exe` — портативная версия, ставить не нужно.

Если Inno Setup не поставился автоматически, скачай его с https://jrsoftware.org/isdl.php и запусти `build.bat` ещё раз. Портативный `LitLauncher.exe` будет готов и без него.

### Способ B: без установки Python (GitHub Actions)

1. Создай репозиторий на GitHub и залей туда все файлы из архива, включая папку `.github`.
2. Открой вкладку **Actions** → **Build Windows exe** → **Run workflow**.
3. Через пару минут скачай готовые `.exe` из блока **Artifacts** (`LitLauncher-windows`).
4. Для постоянного релиза создай тег: `git tag v1.0 && git push --tags`. Файлы появятся в **Releases**.

### Если антивирус ругается

Собранные PyInstaller программы часто ложно помечаются антивирусами, так как у файла нет цифровой подписи. Код открыт: ты собираешь файл сам из `LitLauncher.py`. Если нужно, добавь папку в исключения.

## 1а. Автообновление лаунчера

Когда ты публикуешь новую версию, у всех пользователей сверху появляется жёлтая полоса **«Вышла новая версия лаунчера»** с кнопкой **Обновить**. По нажатию лаунчер скачивает `LitLauncher-Setup.exe`, закрывается и открывает установщик. Он ставится поверх старой версии, настройки и миры сохраняются.

**Один раз настрой:**
1. Открой `LitLauncher.py` и найди строку `UPDATE_REPO = "YOUR_GITHUB_NAME/LitLauncher"`. Впиши свой репозиторий, например `"ivan/LitLauncher"`. Репозиторий должен быть публичным.
2. Залей проект в этот репозиторий (вместе с папкой `.github`).

**Как выпустить обновление:**
1. Внеси правки в код и залей их в репозиторий.
2. Создай тег новой версии: `git tag v1.3 && git push --tags`.
3. GitHub Actions сам соберёт `LitLauncher.exe` и `LitLauncher-Setup.exe`, подставит номер версии из тега и создаст релиз.
4. При следующем запуске у всех появится кнопка «Обновить». Проверить вручную можно в разделе «О лаунчере» → «Проверить обновления».

Тег должен быть больше текущей версии (v1.3 после v1.2). Пока `UPDATE_REPO` не заполнен, проверка выключена.

## 2. Запуск без сборки (из исходников)

- **Windows:** двойной клик по `start.bat`
- **Linux / macOS:** `chmod +x start.sh && ./start.sh`
- или: `python LitLauncher.py`

Нужен Python 3.8+ с tkinter. Linux: `sudo apt install python3 python3-tk`.
Java ставить **не нужно**, лаунчер скачает её сам.

## 3. Первая настройка (мастер)

1. **Ник** — 3–16 символов: латиница, цифры, `_`.
2. **Память** — подставь рекомендуемое значение кнопкой. Больше не значит быстрее: лишняя память увеличивает паузы сборщика мусора.
3. **Оптимизация** — оставь оба переключателя включёнными:
   - JVM-флаги (G1GC, Xms = Xmx, pre-touch, высокий приоритет)
   - Fabric API + Sodium, Lithium, FerriteCore, ModernFix, EntityCulling, ImmediatelyFast
4. **Завершить.**

## 4. Игра

1. Вкладка **ИГРАТЬ** → внизу выбери версию (переключатель «Снапшоты» добавляет тестовые).
2. Нажми большую кнопку **ИГРАТЬ**.
3. При первом запуске версии лаунчер скачивает игру, библиотеки, ресурсы, Java и моды — это занимает несколько минут. Потом запуск быстрый.
4. Ход загрузки виден в полосе прогресса, подробности — по ссылке **Показать лог**.

## 4а. Моды и смена версии

- Вместе с Fabric лаунчер ставит **Fabric API** и моды оптимизации строго под выбранную версию.
- Если ты сменил версию (например, 1.21.11 → 1.20.1), старые моды **лаунчера** удаляются, а новые скачиваются под новую версию.
- Если для версии нет Fabric (например, 1.12.2), моды лаунчера просто удаляются, и игра запускается ванильной.
- Твои собственные моды в папке `mods` лаунчер **не трогает**. Если они не подходят под новую версию, Fabric может не запуститься: убери их вручную.
- Кнопка **Удалить моды** в настройках убирает только моды, поставленные лаунчером.

## 5. Настройки

- **Память (Xmx)** — для ванили 3–4 ГБ, для сборок с модами 4–6 ГБ.
- **Путь к Java** — пусто = автоподбор.
- **Разрешение / полный экран.**
- **Доп. JVM-аргументы** — для опытных.
- **Папка игры** — там лежат `mods`, `saves`, `resourcepacks`.
- **Мастер настройки** — пройти первую настройку заново.

## 6. Где лежат данные

- Windows: `%APPDATA%\.litlauncher`
- Linux: `~/.litlauncher`
- macOS: `~/Library/Application Support/litlauncher`

Внутри: `config.json` (настройки), `minecraft/` (игра), `runtime/` (Java).

## 7. Частые проблемы

| Проблема | Решение |
|---|---|
| `build.bat`: «Python не найден» | Переустанови Python с галочкой **Add python.exe to PATH** |
| `No module named tkinter` | Linux: `sudo apt install python3-tk` |
| Мод не поставился для версии | Для новых версий Fabric/моды могут быть ещё не готовы — запустится ваниль |
| Игра вылетает | Открой лог; уменьши память или отключи моды в настройках |
| Список версий пустой | Проверь интернет, включи VPN или впиши прокси в настройках. Нажми «повторить» над списком |
| Загрузка обрывается | Просто нажми ИГРАТЬ ещё раз — докачает недостающее |
| SmartScreen: «Windows защитила ваш компьютер» | «Подробнее» → «Выполнить в любом случае» (файл не подписан) |

## 8. Важно

Режим входа — **офлайн** (по нику). Серверы с лицензионной проверкой не пустят.
